# Article Summarizer

Generate concise summaries from long-form text.

## Prompt

Uses prompt registry entry: `summarize` (`v2` default).

## CLI example

```bash
byo-llm run summarize "Long article text"
```

## Example output structure

```text
- Key point 1
- Key point 2
- Key point 3
Action item: <recommended next step>
```

See `sample-articles.json` for realistic article-like inputs.
