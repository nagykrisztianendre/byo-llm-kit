BYO-LLM Kit — No Vendor Lock-in

A developer-first Node.js + TypeScript template for shipping AI features with full provider control.

Value proposition

  • Build AI product features without coupling to one model vendor.
  • Start in deterministic mock mode, then add provider adapters.
  • Keep app logic stable while changing inference providers over time.

What you get

  • TypeScript starter structure for AI feature development.
  • Provider-agnostic adapter pattern.
  • Mock-only mode for local development and CI testing.
  • GitHub Codespaces devcontainer setup.
  • CI workflow with lint, typecheck, tests, and build checks.

How it works

  1. Clone the template and open it in Codespaces.
  2. Build features against the adapter interface in mock mode.
  3. Add or swap provider adapters as needed.
  4. Ship with the same app-facing feature code.
