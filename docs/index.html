Ship BYO-LLM features in 30 minutes — no vendor lock-in

BYO-LLM Kit is a fast Node.js + TypeScript starter for teams that want to prototype in mock mode and switch providers later without rewriting product logic.

What the kit includes

  • Provider abstraction for generation workflows.
  • Deterministic mock provider for keyless local development.
  • Hugging Face and Replicate adapters.
  • Minimal example web app with server-side provider calls.

Supported providers

  • Mock (default): zero keys, deterministic output.
  • Hugging Face: configure HF_TOKEN and HF_MODEL.
  • Replicate: configure REPLICATE_API_TOKEN and REPLICATE_MODEL.

How it works in Codespaces

  1. Open this repository in GitHub Codespaces.
  2. Run pnpm install.
  3. Run pnpm dev and open forwarded port 3000.
  4. Test with mock mode first, then switch providers when ready.
